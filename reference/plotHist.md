# Plot shadow Histograms

Plot shadow Histograms

## Usage

``` r
plotHist(dist, groups, n, bw.filt = NULL, gr.filt = NULL)
```

## Arguments

- dist:

  distance matrix

- groups:

  group assignment vector

- n:

  number of points in distance matrix

- bw.filt:

  optional filter "within" or "between or vector of both for columns to
  display.

- gr.filt:

  optional filter of groups to show

## Value

ggplot
